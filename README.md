## Datos personales

Ya están completos en `index.html` (nombre, Duoc UC y contacto). Si cambias algo, edita `index.html` y vuelve a subirlo.

## Publicar en GitHub Pages

1. Crea un repositorio, por ejemplo `tu-usuario.github.io` (queda en `https://tu-usuario.github.io`) o cualquier nombre (queda en `https://tu-usuario.github.io/nombre`).
2. Sube el **contenido** de esta carpeta a la raíz del repositorio (que `index.html` quede en la raíz).
3. En el repositorio: **Settings → Pages → Build and deployment → Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Espera un par de minutos y abre la URL.

También funciona abriendo `index.html` directo desde tu computador.
